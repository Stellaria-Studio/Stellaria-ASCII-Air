# ASCII SKY // 操作与战术指南

> **LOCK THE SIGNAL. OWN THE SKY.**
> 锁住信号，掌控天空。

ASCII SKY 是一套在浏览器中运行的简化 3D 空战模拟：飞行、地形、传感器、弹道和碰撞在三维世界中计算，再以字符化战术显示器呈现。它借鉴现代战斗机的操作逻辑，但不是任何现役型号的训练器，也不代表真实武器的保密性能。

## 1. 本地启动

1. 解压 `ASCII-SKY-WebApp.zip`。
2. 双击 `index.html`，建议使用最新版 Chrome、Edge 或 Chromium。
3. 点击 `ENTER LOADOUT`，选择飞机、敌机数量、难度和雷达显示后开始。
4. 点击游戏画面取得鼠标锁定；按 `Esc` 暂停并释放鼠标。

独立版不需要安装 Node.js，也不访问在线站点。WebGPU 不可用时会自动切换到 Basic-Web-Core CPU 投影路径。

## 2. 飞行控制

| 输入 | 作用 |
| --- | --- |
| 鼠标 | 机体系飞控指令；向上拉起、向下压杆、左右给滚转指令 |
| `W` / `S` | 压杆 / 拉杆 |
| `A` / `D` | 左滚 / 右滚；不附加偏航 |
| `Q` / `E` | 左 / 右方向舵 |
| `Shift` / `Ctrl` | 增加 / 减少油门 |
| `B` | 减速板 |
| `Z` | 鼠标指令环回中 |

油门 `0–100%` 是军用推力，`101–110%` 是加力。加力可以持续保持，但会积累热量：连续工作约 30–40 秒后热量达到 70%，HUD 才展开 `HEAT` 热量条并触发 `AB OVERHEAT`，系统自动把油门退回 100%。热量完全冷却到 0 后，稳定加力权限恢复。

过热锁定期间仍可再次按 `Shift` 推过 100%，这属于 `AB OVRD` 强制加力。强制加力会继续升温；到达 100% 时发动机和机身会受到永久损伤、推力显著降低。较低油门可以更快冷却。

鼠标和键盘都作用在飞机自身坐标系。松开滚转键会停止继续滚转并保持当前姿态；系统不会为了“回正地平线”强迫飞机抬头。

## 3. HUD 与能量

- 左侧速度带：`CAS` 指示空速；其下显示 `TAS` 和马赫数。
- 右侧高度带：海拔高度；`RALT` 是距正下方地形的雷达高度。
- 中央速度矢量符号表示当前飞行轨迹，机炮固定基准在 HUD 中心附近。
- `G`、`α`、`β` 分别是过载、迎角和侧滑角。
- `ENERGY` 为能量变化率；负值说明正在用高度或速度支付机动。
- `PULL UP` 与 `TERRAIN` 为近地预测告警，应立即减小坡度并建立爬升。

### 失速与尾旋

失速告警会在真正离开可控包线之前出现。恢复条不是倒计时，而是由空速、迎角和旋转状态共同计算；只有它接近 100% 且告警消失，才表示飞机真正恢复。

失速改出：

1. 按 `W` 压低机头并卸载。
2. 把机翼滚到接近水平，避免继续拉杆。
3. 使用军用推力建立空速；不要在高迎角下突然开满加力。
4. 迎角和空速恢复后再柔和拉起。

尾旋改出：

1. 按 `W` 压机头。
2. 按 HUD 指示使用反方向 `Q/E` 方向舵。
3. 把油门降至 55% 以下。
4. 旋转停止、空速恢复后，方向舵回中并柔和拉起。

## 4. 火控雷达

| 模式 | 用途 |
| --- | --- |
| `SRC` | 大范围搜索，覆盖宽但航迹更新较慢 |
| `TWS` | 边扫描边跟踪，最多维持 4 条航迹；`T` 循环当前 L&S |
| `ACM` | 机头前方小范围快速截获，适合近距格斗 |
| `HMD` | 头瞄截获；把鼠标圆环放到目标上并按 `H` |
| `STT` | 单目标窄波束持续跟踪；半主动雷达弹需要此模式支持 |

- `R`：在 `SRC → TWS → ACM → HMD` 间切换。
- `T` 或鼠标右键：指定、锁定或循环目标。
- `H`：立即进入头瞄截获并尝试锁定圆环内目标。
- `X`：取消目标并回到先前搜索模式。
- 任务设置可选择方形 `B-SCOPE / ATTACK` 或 `PPI / SITUATIONAL` 显示。

低空、俯视目标和目标径向速度很低时会出现地面杂波与多普勒盲区。雷达航迹可能转为 `COAST`，锁定也可能中断。

### 传感器模拟原理

游戏不向 AI 或武器直接提供“全知坐标”，而是把目标真值经过不同传感器模型转为有误差、有寿命的航迹：

- **脉冲多普勒雷达**：探测距离受目标距离、雷达损伤、扫描波束、地形视线和俯视背景影响。目标相对雷达的径向速度很低时会进入多普勒盲区，低空地表回波会进一步降低信噪比。
- **扫描与航迹**：`SRC` 覆盖宽但更新慢；`TWS` 在继续搜索时维持多条预测航迹；`STT` 把波束集中在一个小门内。失去新量测后航迹先进入 `COAST`，按最后速度外推并扩大不确定度，随后才变成 `LOST`。
- **地形遮蔽**：雷达、红外导引头和 RWR 都需要近似视线通畅；山体或建筑可以截断探测与制导，导弹本身也会撞击地形和建筑。
- **RWR**：只显示正在辐射且满足传播/视线条件的威胁，并区分搜索、跟踪、锁定和导弹告警；它不是目标测距雷达。
- **红外传感器**：比较目标热源与天空、太阳和地面背景的对比度。目标尾后发动机喷流、加力或受损高温会增强信号；正面、远距离、太阳邻近方向和低空热背景会降低捕获质量。
- **干扰物**：箔条降低雷达弹航迹质量；热焰弹作为一个短寿命、高强度、快速减速的红外假目标。是否诱骗成功取决于距离、原锁定质量、导引头视场和背景，不是固定概率的“免疫键”。

## 5. 武器

| 选择 | 武器 | 操作与制导逻辑 |
| --- | --- | --- |
| `1` | `GUN` | 左键射击；EEGS/LCOS 根据目标航迹、相对速度、弹速和重力给出预测弹着环 |
| `2` | `ST-1` | 被动成像红外格斗弹；按视场、离轴角、热对比度和背景建立锁定 |
| `3` | `ST-1X` | 半主动雷达弹；发射前和飞行中都必须保持同一目标的 `STT` 照射 |
| `4` | `ST-1AX` | 主动雷达弹；惯导起飞，航迹有效时接受数据链中段更新，接近目标后转自身雷达末制导 |

- `V` 或鼠标中键：循环武器。
- `Space`：发射当前导弹。
- 机炮无需先选中，左键始终可以射击；选择 GUN 后才显示完整机炮 HUD。
- 武器面板中的 `BOOST / MIDCOURSE / COAST / TERMINAL / LOST` 表示最近一枚己方导弹的制导阶段。
- 导弹发动机只在助推/续航段工作；白色烟迹在发动机熄火后仍会逐渐扩散和消失，因此烟迹不等于导弹仍在加速。

机炮解算可在较远距离建立，但只有距离、航迹质量和瞄准误差同时满足时才显示 `GUN SHOOT`。远距离解算误差更大，短点射并观察曳光更有效。

### 导弹技术原理

- **ST-1 红外格斗弹**：导引头被动接收红外能量，本身不发射雷达信号。头瞄允许较大的离轴捕获；发射后使用视线角变化和目标相对运动形成比例导航式提前量。成像/背景判别会压制部分热焰弹，但太阳、热地表、低对比度和越出导引头视场仍可造成脱锁。
- **ST-1X 半主动雷达弹**：导弹接收目标反射的母机雷达能量，因此整个交战阶段都要求同一目标保持 `STT`。照射中断后只有很短的记忆飞行时间，无法像主动弹一样自行搜索。
- **ST-1AX 主动雷达弹**：离架时载入目标位置和速度，先用惯导飞向预测截获点；母机航迹有效时通过数据链修正预测。进入自身雷达捕获区后切换 `TERMINAL`，此后可自主跟踪。数据链中断时会显示 `COAST`，按最后信息继续飞行，但误差持续增大。
- **动力与能量**：固体火箭发动机只有有限的助推/续航时间。熄火后导弹继续滑翔，速度因阻力下降；每次大角度修正都会消耗能量。屏幕烟迹会比发动机燃烧持续更久，不能用“仍有白烟”判断导弹还在加速。
- **引信**：末段导引质量、最近通过距离和武器类型共同决定近炸；没有可靠末制导的导弹不会仅因飞过目标附近就自动命中。

## 6. RWR、规避与干扰物

- `F`：发射热焰弹；`G`：投放箔条。HUD/RWR 区域显示剩余数量。
- RWR 威胁级别依次为搜索、跟踪、锁定和导弹告警。
- 雷达弹来袭时可让威胁位于 3/9 点方向，保持横切并配合箔条；低空地面背景会进一步降低导引头锁定质量。
- 红外弹更依赖热焰弹、视线遮断和大角度机动。
- 导弹有有限动力段和能量；让它持续转弯通常比单次急拉更有效。

## 7. 损伤与坠毁

损伤面板与飞行模型使用同一组部件数据：机身、左右机翼、发动机、飞控、雷达和尾翼。绿色表示正常或轻伤，琥珀色表示性能下降，红色并标记 `DEST` 表示部件损毁。

- 单侧机翼损坏会产生不对称滚转和升力损失。
- 发动机损坏会降低推力并产生不稳定声音。
- 飞控/尾翼损坏会降低操纵权限；雷达损坏会缩短有效探测距离。
- 严重结构损坏后任务不会立刻切黑屏；视角保留到飞机撞击地形或建筑。
- 导弹命中会产生红色冲击晕影、画面冲击线、专用音效和 `MISSILE IMPACT` 提示，应立即查看损伤图并判断是否仍可控。

## 8. 常见问题

- **进入后没有画面**：请用 Chrome/Edge 打开解压后的 `index.html`，不要只预览 ZIP 内文件。
- **没有声音**：浏览器要求先有一次鼠标点击才能解锁音频；点击游戏画面开始即可。
- **鼠标不能控制**：点击游戏画面取得指针锁定；若按过 `Esc`，点击 `RESUME`。
- **半主动弹发射后立刻丢锁**：保持目标为 `STT`，不要切雷达模式或取消目标。
- **主动弹显示 COAST**：母机航迹暂时丢失，导弹正在按最后一次惯导预测飞行；恢复航迹可继续中段更新，进入末制导距离后由自身雷达尝试捕获。
- **加力自动退回 100%**：热量达到 70% 后触发了热保护。把油门保持在军用推力或更低，等待热量条降到 0；过热期间再次推入加力属于风险覆盖。
- **ST-1 无法发射**：目标可能越出导引头离轴范围、红外对比度过低，或太阳/地面背景过强。用 `H` 头瞄重新截获、缩短距离或转到目标尾后。
- **恢复条满得很慢**：仍有高迎角、低空速或旋转条件未解除；继续卸载并建立空速，不要仅按住改出按键等待。
