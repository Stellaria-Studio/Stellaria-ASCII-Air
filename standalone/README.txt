ASCII SKY // ST COMBAT SYSTEM
============================

Source, updates, and MIT license:
https://github.com/Stellaria-Studio/Stellaria-ASCII-Air

完整操作、HUD、雷达、武器、失速/尾旋和损伤说明见同目录 USER_GUIDE_CN.md。

本地运行：
1. 解压 ZIP。
2. 直接双击 index.html。
3. 建议使用最新版 Chrome、Edge 或 Chromium。

这是单文件 Web App：游戏代码、样式和 StSL 生成的 WebGPU Shader 都已内嵌到 index.html，不访问 Sites，不需要网络或安装 Node.js。

如果浏览器未开放 WebGPU，游戏会自动使用 Basic-Web-Core CPU 投影路径，仍可运行。

基本操作：
- 鼠标：机体系 FBW；左右给横滚角速度、上下给拉/推杆角速度，回到中位只停止旋转并保持当前姿态，不把飞机强制回正
- W：压杆；S：拉杆，可连续完成 360° 筋斗
- A/D：左滚/右滚；松键后保持当前姿态，不自动回中，按住时不耦合偏航
- Q/E：方向舵
- Shift/Ctrl：油门；0–100% 为军用推力，101–110% 为持续加力。约 30–40 秒达到 70% 热告警并自动退回 MIL；冷却至 0 前再次推入加力属于覆盖，到 100% 会损坏发动机
- B：减速板；Z：瞄准环回中
- R：雷达模式
- T 或鼠标右键：锁定/循环目标；TWS 会同时维持最多 4 条航迹，T 只轮换当前 L&S；X：取消目标
- V 或鼠标中键：循环武器
- 1/2/3/4：机炮 / ST-1 近距红外 / ST-1X ACM 半主动 / ST-1AX TWS 主动雷达
- 鼠标左键：随时发射机炮，不必先选择 GUN
- Space：发射当前选中的导弹；HUD 显示 SHOOT 才处于发射区
- F/G：Flare / Chaff
- Esc：暂停并释放鼠标

飞行提示：
- 鼠标向上与 S 同样拉起飞机，但会更早介入迎角与 9G 保护；鼠标横向不会再把飞机拉回某个目标坡度。
- 任务设置里的 FCR DISPLAY 可选择方形 B-SCOPE 攻击雷达或 PPI 态势显示。
- 对雷达制导导弹保持威胁在 3/9 点方向横切，降低径向速度并利用低空地面杂波，再配合 G 箔条和大过载转向，可使导弹脱锁或耗尽机动能量。
- STALL 时按 W 压低机头、卸载并建立空速。
- SPIN 时按 W 压机头，同时按 HUD 提示使用反方向 Q/E 方向舵，并将油门降到 55% 以下；旋转停止后松开控制并从俯冲中柔和拉起。
- HUD 左下方机体图显示机身、左右机翼、发动机、尾翼、飞控和雷达的分区损伤。
- 严重损伤不会立刻结束任务；视角会保留到飞机真正撞击地面或建筑。
